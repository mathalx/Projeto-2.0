# Change 002: Estrutura de Recursos Visuais (Assets)

## Objetivo
Criar uma estrutura organizada para armazenar os recursos visuais utilizados nas
telas do Streamlit, preparando o projeto para futuras melhorias de experiência
do usuário.

## Escopo
- Criação da pasta `assets/` na raiz do projeto.
- Criação das subpastas `assets/images`, `assets/icons`, `assets/styles` e
  `assets/logo`.
- Criação de arquivos `.gitkeep` para preservar as pastas vazias no Git.
- Documentação da estrutura em `assets/README.md` e
  `docs/acnnorte/05-recursos-visuais.md`.
- Atualização da árvore de diretórios em `docs/acnnorte/01-arquitetura.md`.

## Fora de escopo
- Mover arquivos existentes.
- Alterar imports, funcionalidades, componentes ou telas.
- Modificar armazenamento de dados (`data/`) ou autenticação.
- Aplicar melhorias visuais nesta change.
