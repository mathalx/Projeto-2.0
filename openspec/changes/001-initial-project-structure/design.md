# Design: Estrutura Inicial e Versionamento

## Arquitetura
A aplicação é estruturada em camadas modulares:
- `src/core/`: Configurações e infraestrutura base.
- `src/modules/`: Domínios de negócio isolados.
- `src/shared/`: Componentes e utilitários reutilizáveis.
- `storage/`: Persistência local de arquivos gerados.
- `tests/`: Bateria de testes automatizados.
