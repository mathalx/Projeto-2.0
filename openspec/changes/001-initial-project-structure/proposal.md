# Change 001: Estrutura Inicial e Versionamento do Projeto

## Objetivo
Estabelecer a estrutura topológica de diretórios e arquivos do aplicativo, garantindo uma arquitetura modular, organizada, escalável e de fácil manutenção, além de configurar o controle de versão Git e GitHub.

## Escopo
- Criação da estrutura de diretórios completa.
- Configuração do Git, `.gitignore`, `.gitattributes`, `requirements.txt`, `README.md`.
- Documentação inicial e guia de versionamento.
